# TooLexicon

# **要件定義**

### **目的**

- 現場で使われる工具の正式名称・通称・略称の混在による認識齟齬を防ぐ。
- 新人や異動者が迅速に工具を特定できるようにし、作業効率・安全性を向上させる。
- スマホ使用が制限される職場でも使えるよう、紙での参照手段を提供する。

---

### **想定ユーザー**

- 中小製造業や建設現場の作業員
- 新人・異動者
- 購買・資材担当者
- 安全教育担当者

---

### **利用環境**

- **スマホ使用可能な現場**：Webアプリから直接検索・閲覧可能（Amazon API画像＋商品情報リンクあり）
- **スマホ使用制限ありの現場**：会社ごとに選択した工具リストをPDF化し、自前撮影画像に差し替えて印刷利用

---

### **主な機能**

### **基本機能**

1. **工具データ登録**
    - 正式名称
    - 通称・略称（複数登録可）
    - 用途・サイズバリエーション
    - 安全上の注意事項
    - AmazonURLとリンク画像取得
2. **編集・削除**
    - 登録内容の修正・削除
    - 通称・略称の追加編集
3. **検索**
    - キーワード検索でサジェスト型に寄せる
    - 正式名称／通称・略称から検索
    - カテゴリ・タグ検索
    - 部分一致検索
    - 直近の履歴とよく検索されるキーワード
4. **画像表示**
    - **Web版**：Amazon APIから取得した商品画像と価格情報を表示（Amazon商品ページリンク付き）
    - **印刷／PDF版**：自前撮影画像や許可済み素材のみ使用（Amazon API画像は含めない）
5. **印刷／PDF出力**
    - 工具を選択してPDF生成
    - 自前撮影画像や許可済み素材のみ使用
    - 用途・注意事項付きレイアウト
    - 印刷向けに簡易レイアウト最適化
    
    **非機能要件**
    
    - **UI/UX**：現場前提の片手操作、詳細画面ではスマホ画面におおまかな内容が入るようにする（細かいのはスワイプ必要）
    - **レスポンシブ対応**：スマホメインだがPCもありで両方で快適に動作
    - **パフォーマンス**：検索結果は1秒以内表示を目標
    - **セキュリティ**：登録・編集は認証ユーザーのみ可能

---

### **拡張機能（将来検討）**

- **画像検索**：カメラ撮影で類似工具を検索
- **音声検索**：音声入力で名称検索
- **多言語対応**：外国人作業員向け（ベトナム＞中国＞フィリピン）ひらがな表記加えたり

---

### **制約・課題**

1. **Amazon API利用規約遵守**
    - API画像はWeb表示時のみ使用
    - Amazonリンクを必ず併記
    - 印刷物やPDFには含めない
2. **商用利用時の安全性確保**
    - PDFや印刷物は自前撮影・社内許可素材のみ使用
3. **現場環境対応**
    - スマホ不可の現場でも利用可能な印刷運用を前提に設計
    - 一部の工具は名称や呼び方が地域・世代・業界特有のため、標準化が難しい場合がある。

---

### **成果物（ポートフォリオ時点）**

- Webアプリ（レスポンシブ対応）
- 工具登録・検索・編集・削除が可能
- すべての名称での検索が可能
- PDF出力対応（印刷可能な状態）
- デモ用データ（10〜20工具程度）
